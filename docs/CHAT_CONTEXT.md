# S^erap^S — контекст чата (только работа над игрой)

> Сжатая история диалога с пользователем **Sora Masora** с момента, когда началась работа над визуальной новеллой S^erap^S. Технические детали — в `docs/AI_CONTEXT.md`, сюжет — в `docs/concept.md`.

## Правила работы (выработанные в чате)
- Общение **по-русски**, коротко: сначала результат, в конце — честные ограничения.
- **После каждой значимой правки — бэкап-коммит** в GitHub `SoraMasora/serap-s-novel`, ветка `main` (`tools/mkpush.py` → GitHub MCP `push_files` с `arguments_file_path`, ≤ 1 МиБ на коммит; тяжёлые ассеты — отдельными коммитами; удаление — `delete_file`).
- Результат отдавать **одним HTML-файлом** `serap-s.html` (все ассеты внутри, `python3 tools/build.py`); HTML в репозиторий не пушить.
- Картинки — Notion `images_generate` с референсами (мастер-кадр Серы, фоны). Пользователь присылает скриншоты с проблемами — исправлять именно то, что видно.
- Перед сдачей — автопрохождение (`play2.cjs`) и скриншоты изменённых мест.
