# CG сцен выбора · 0.7.0

89 записей в `choice-cg.json`: 86 целевых сцен + чайный вариант `m2_roof_b_ns` + положительные `c1_hand_ok`/`c1_hug_ok`.

Источники: иллюстрации, сгенерированные по кадрам и дизайну игры. WebP 1376×768 q85 встроены в `assets/cg12.js`…`cg29.js`, подключены в index.html. Экспорт создаёт `godot/assets/bg/cg_<scene>.webp` и каталог `godot/data/choice_cg.json`; бинарники не коммитятся.

Реплики/условия/флаги/отношения/переходы неизменны. CG активируется перед первым диалогом после проверок ветки и прячет спрайты; фон/спрайты возвращаются перед следующей визуальной командой или переходом. Каталог охватывает текстовые реакции, а не роутеры выбора локации. Проверки и ограничения: ../verification/v0.7.0.md.
