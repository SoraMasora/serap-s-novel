# ADR-0003: паритет логики через JS-эталон и digest трассы
**Решение:** `tools/godot/js_reference.cjs` исполняет оригинальные `run()`-правила и лямбды на 200 сидах тем же ГПСЧ, что `AutoPlayer`; тест сравнивает digest/концовку/шаги/статы.
**Контекст:** условия `when` в JS — лямбды; при переводе в Expression легко ошибиться.
**Альтернативы:** ручные сценарии (покрывают единицы путей); сравнение скриншотов (дорого, хрупко).
**Последствия:** любое расхождение логики ловится за ~2 с; эталон перегенерируется при изменении сюжета.
**Проверка:** 200/200 совпадений (концовки home 148, neutral 19, good 13, gone 11, bad 8, letters 1; «expo» сидами не достигнута). **Откат:** удалить фикстуру и тест.
