# ADR-0006: iOS — экспорт Xcode-проекта на любой ОС, неподписанный .ipa на macOS
**Решение:** пресет iOS с `application/export_project_only=true` (Godot пишет Xcode-проект и `serap.pck` даже на Linux), `targeted_device_family=2` (iPhone+iPad), iOS 14+, ориентация из `window/handheld/orientation` (альбомная), тёмный экран запуска; `app_store_team_id="UNSIGNED00"` — заглушка (Godot не экспортирует без Team ID). Сборка: `xcodebuild … CODE_SIGNING_ALLOWED=NO` на macOS → `Payload/serap.app` → `serap-unsigned.ipa`; подпись — у пользователя (Sideloadly/AltStore/Xcode с его Apple ID). CI: Linux job экспортирует проект (артефакт `ios-xcode-project`), job `ios` на `macos-15` собирает .ipa (артефакт `ios-unsigned-ipa`).
**Контекст:** в среде агента нет macOS; у пользователя может не быть платного Apple Developer. Секреты подписи в репо не хранятся.
**Альтернативы:** полный экспорт с подписью на macOS (нужны сертификат и профиль в секретах CI); только веб-PWA через Safari (без нативного приложения, KI-012); TestFlight/App Store (платный аккаунт).
**Последствия:** код игры одинаков для Android/iOS/веба (слой Mobile из ADR-0005); на iOS нет кнопки «назад» — выход в меню через быстрое меню; бесплатный Apple ID — переустановка/переподпись каждые 7 дней (KI-014).
**Проверка:** `bash tools/godot/ios_build.sh` на Linux → Xcode-проект, Info.plist (альбомная, UIRequiresFullScreen, UIStatusBarHidden), pbxproj (bundle com.soramasora.seraps, iOS 14.0, TARGETED_DEVICE_FAMILY "1,2", 0.19.0/19) — PASS. `xcodebuild` и запуск на iPhone — UNVERIFIED (KI-010).
**Откат:** удалить job `ios`, `tools/godot/ios_build.sh`, вернуть `export_project_only=false`.
