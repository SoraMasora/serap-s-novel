# Android 0.7.4-android.1

Мобильная версия 0.7.4: тот же сюжет, 7 CG смертей и все 5 вариантов скримера. Порог открытия петли — 7 разных исходных концовок — не менялся.

## Установка

1. Скачайте `SERAPS-0.7.4-Android.apk` на телефон и откройте файл.
2. Если Android запросит разрешение на установку из этого источника, разрешите его только приложению, из которого открываете APK. После установки разрешение можно убрать.
3. Играйте горизонтально; поддерживаются оба поворота экрана. Интернет не нужен.

Это APK для самостоятельной установки: release-движок Godot 4.7.2, **локальная тестовая подпись**, не публикация в Google Play. Приватный ключ не входит ни в архив, ни в репозиторий. С другой подписью Android не разрешит обновление старой установки. Не удаляйте прежнюю игру без резервной копии: удаление стирает локальные сохранения.

Фактический манифест: Android 7.0/API 24+, target API 36, ARMv7 + ARM64; требуется OpenGL ES 3.0. Работа на конкретных старых моделях не гарантирована. Лимит кадров 60 — не обещание стабильных 60 FPS на любом устройстве.

## Управление

- Карта: левый джойстик — идти, внешний край — бежать. Справа «Бег» можно удерживать вторым пальцем; «Действие» появляется около доступной точки.
- Касание самой карты — идти к указанному месту. На качелях: «Назад», «Вперёд», «Встать». Крупный план закрывается кнопкой «Назад» или касанием.
- Диалоги и выборы — касанием; кнопки интерфейса увеличены. В дыхательной мини-игре удерживайте палец при вдохе, отпускайте при выдохе.
- Системная кнопка/жест Android «Назад» — меню, повторное нажатие — закрыть меню.
- При открытом меню джойстик и действия отпускаются, карта приостанавливается. При потере фокуса/сворачивании удержания сбрасываются. При паузе приложения сохраняются память/прочитанное и доступный автосейв, дерево сцены приостанавливается до возврата.
- «Смягчить вспышки и мерцание» сохраняет спокойный вариант скримера без строба и тряски.

## Мобильный профиль

- Большие сенсорные зоны: кнопки не ниже 64 единиц в 720p-координатах, действия карты 176×88, джойстик 230×230; текст реплик 26. Окно реплик занимает нижние 40% вместо 30% на ПК.
- Safe area учитывает вырезы и системные отступы. Проверены расчёты отступов и десктопная эмуляция вёрстки 1280×720 и 1600×720; реальный вырез телефона отдельно не проверен.
- Дождь: 180 капель вместо 650; пыль/снег титула: 20 частиц. Не меняются сюжетные эффекты скримера.
- LRU-кеш — до 24 текстур; текстуры, используемые текущей сценой, остаются живы. Размер и потребление памяти всего приложения зависят и от активных ресурсов сцены.
- Только в Android staging-копии: фоны/портреты/CG не больше 1280 по длинной стороне, ETC2, без mipmaps. Исходный арт проекта не перезаписывается. Это экономит графическую память, но увеличивает APK по сравнению с WebP-исходниками. ARM32 и ARM64 входят в один APK (~249 MiB).
- Скрытый SubViewport карты не перерисовывается; аппаратный курсор на Android не загружается. Полноэкранный режим не переключается через десктопную настройку.

## Сборка

Нужны **Godot 4.7.2**, официальный `android_release.apk` этой версии, JDK, Android SDK с `build-tools;35.0.0`, `platform-tools`. Шаблон поставляется в официальном export templates TPZ. Использован ZIP-экспорт, без Gradle.

```bash
python3 tools/godot/build_android.py \
  --godot godot \
  --sdk "$ANDROID_HOME" \
  --java "$JAVA_HOME" \
  --template /path/to/4.7.2/android_release.apk \
  --stage /path/to/NEW-empty-build-directory \
  --out /path/to/SERAPS-0.7.4-Android.apk
```

Скрипт создаёт новую staging-папку, меняет только её импорт-профили, дважды импортирует проект (KI-004), экспортирует release APK, выполняет zipalign с 16-KiB страницами и подписывает стандартным локальным debug-ключом. При отсутствии ключ создаётся вне проекта (`~/.android/debug.keystore`); для последующих обновлений сохраните тот же ключ. Для магазина нужен собственный release/upload-ключ и отдельная процедура публикации.

## Проверка

Актуальные результаты: `docs/verification/android-0.7.4.md`.

```bash
# Мобильный профиль + все GUT-тесты
SERA_TOUCH=1 GODOT_DISABLE_LEAK_CHECKS=1 godot --headless --audio-driver Dummy \
  --path godot -s res://addons/gut/gut_cmdln.gd -gdir=res://tests -ginclude_subdirs -gexit

# Запуск того же интерфейса на ПК; GUI-экран необходим
SERA_TOUCH=1 godot --path godot

# Визуальный smoke: два настоящих InputEventScreenTouch через viewport,
# реальное движение героя, отпускание, меню; --out — каталог скриншотов
SERA_TOUCH=1 SERA_WIDE=1 godot --path godot --windowed \
  -s res://tools_dev/mobile_preview.gd -- --out=/tmp/seraps-mobile-shots

node tools/godot/verify_preservation.cjs --mobile
```

`verify_preservation` без флага продолжает строго сравнивать весь исходный 0.7.3 и ожидаемо отклоняет изменённые для Android контроллеры. `--mobile` принимает только перечисленные SHA256 в `data/mobile074_overrides.json`; все прочие защищённые файлы, исходные сцены, концовки и ссылки ресурсов проверяются без послаблений. Полный `story.json` дополнительно сопоставлен с поставленной 0.7.4.
