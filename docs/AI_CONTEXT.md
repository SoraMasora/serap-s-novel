# S^erap^S — контекст проекта для следующего ИИ

> Этот файл — передача дел. Прочитай его целиком, прежде чем что-то менять.

## 1. Кто пользователь и как с ним работать
- Пишет **по-русски**, отвечать по-русски, кратко, по делу.
- Делает браузерную визуальную новеллу **S^erap^S** (концепт: `docs/concept.md`).
- **Обязательно делать бэкапы на GitHub** после каждой значимой правки: репозиторий **https://github.com/SoraMasora/serap-s-novel** (owner `SoraMasora`, ветка `main`, публичный).
- После правок отдавать пользователю **единый HTML-файл** `serap-s.html` (все ассеты внутри) — его в репозиторий не пушить (> 1 МБ).
- Пользователь присылает скриншоты с проблемами — исправлять именно то, что видно (анатомия рук, рукава, «левитация» и т.п.).

## 2. Сюжет и персонажи
**Серафима (Сера)**, 19 лет — сбежала из семьи пастора-фанатика. Работает ночным кассиром в круглосуточном, заочно учится в художественном колледже, рисует ангелов с обломанными крыльями, собирает кресты, не спит по ночам. Герой (имя вводит игрок, по умолчанию «Кирилл») — новый сосед по лестничной площадке.

Структура:
- **Глава 1 «Соседка»** (`c1_*`, переписана в v4 по файлу пользователя sToRy.docx): дождливая улица → герой (затворник) сталкивается с незнакомкой «???» в магазине (`c1_store*`) → она ловит его у двери и просит мицеллярку, знакомство (`c1_door`) → комната героя → день 2: снова магазин, крик за стеной, Сера врезается в него лбом, таракан (`c1_day2`, `c1_bug*`) → её картины (выбор отзыва) → дальше как раньше → прогулка (кафе / крыша / учёба) → гости в пальто → пастор (двор из окна + лестница) → ночь на крыше (исповедь) → `ch2`.
- **Глава 2 «Ближе»** (`ch2`, `d1`–`d3`, `eve1`–`eve3`): **пиксельная прогулка** по двору, 3 дня × 2 визита. Точки: `valya`, `cafe`, `store`, `college`. Сцена выбирается как `<точка>_<номер визита>` (1..3). Вечером каждого дня — сцена с Серой, зависящая от флагов.
- **Глава 3 «Решение»** (`ch3`): предложение сходить к психологу → `end` → `pickEnding()`.
- **Концовки**: `end_good` «Свет в конце тоннеля» (feel ≥ 80, `defended`, `therapy`), `end_bad` «Падший ангел» (feel < 40 или press ≥ 3 без `defended`), иначе `end_neutral` «Тихая гавань».

## 4. Формат сценария (`js/story.js`)
- `['~', 'текст']` — **внутренний голос героя** (стиль «мысли», голубой курсив). `['???', 'текст', 'эмоция']` — Сера до знакомства (эмоция применяется к Сере).
- `{sfx:'door|keys|steps|step|bump|drop|knock|enter'}` — процедурные звуки (audio.js, `Sound.sfx`).
- `['Имя', 'текст', 'эмоция']` — реплика. Для `'Сера'` третий элемент меняет её эмоцию, для `'P'` — портрет героя. `['', 'текст']` — повествование / мысли героя. `{P}` в тексте → имя игрока.
- Команды: `{chapter}`, `{card:['Глава 2','Ближе']}` (заставка главы), `{bg}`, `{zoom:true}`, `{music:'calm|sad|warm|tense'}`, `{rain:true|false}`, `{show:'эмоция'}` или `{show:'x', who:'valya', pos:'left|center|right|fl|fr'}`, `{hide:'who'|'all'}`, `{fx:'shake'|'flash'}`, `{react:'pat|tongue|hop|shy|shake|shiver|wipe|frown|down'}`, `{feel:+N}`, `{set:{flag:true}}`, `{add:{press:N}}`, `{note:'факт'}`, `{when:s=>…, go:'метка'}`, `{go}`, `{choice:[{t, hint, feel, set, add, go, react}]}`, `{map:{title, task, time:'day|eve|night', visits, spots:[…], after, music}}`, `{tomap:true}` (конец сцены локации), `{ending:true}`, `{final:'good|neutral|bad'}`.
- Доверие `feel` (0–100, старт 50) **скрыто** — шкалы на экране нет и не должно быть. `press` — счётчик давления. `notes` — «Заметки о Сере» (кнопка «Заметки» / клавиша N; 28 штук).
- Флаги главы 2: `v_<точка>` (число визитов), `valyaAlly valyaWarned jam timurOk candy promise metLiza choir lizaKnows lizaGift lizaGiven sang helpStudy goesClass expo expoYes slept heard defended stood art silent therapy`.

## 5. Движок — важное
- Спрайт персонажа: `div.char > div.shiftw > div.idle > img.base + img.blink`. Idle: CSS-анимация дыхания/покачивания + JS `idleLoop` (моргание, смена веса).
- **Клик по Сере ничего не делает** (пользователь просил убрать). Реакции — только из сценария и при выборах (`feel ≥ 10 → pat`, ≥ 5 → hop, ≤ −12 → shake, < 0 → shiver). Если Сера плачет (`sad*`), реакции заменяются на `wipe/frown/down` (CRY_MAP).
- **Дождь** рисуется на `canvas#fx`, который стоит **под** `#chars` — капли на весь экран, но не поверх персонажей. Пользователь хотел стиль как на референсе: длинные тонкие светлые полосы, лёгкий наклон. **Дождь (и капли, и звук) — только на открытых локациях** (`OUTDOOR` в engine.js: street, roof, court; функция `applyRain()`). В помещениях (магазин, кафе, комнаты, кухня, лестница, колледж, вид из окна `yard`, пустая комната) дождя нет совсем.
- Сохранения: 6 слотов + авто (`localStorage`: `serap_save_N`, `serap_save_auto`, `serap_opts`, `serap_endings`). В режиме карты сохраняется `st.mode='map'` и `st.map` (с позицией героя).
- Для тестов есть `window.__pix = { enter(id), state() }`.

## 5.2 v5: камера, катсцены, крупные спрайты
- `{cam:{x,y,s,ms}}` — наезд камеры на точку фона (x,y в %), сбрасывается любым `{bg}`; `{cam:null}` — сброс.
- `{cut:[{img,ms,text,sfx}]}` — катсцена: кадры из `A.bg` (файл `assets/cg1.js`: bug1..bug4, bug_art) сменяются сами, клик — следующий кадр, текст пишется в журнал.
- Реакция `pat`: покадровая анимация «Сера гладит экран» (`sera_pat` → `sera_pat2`/`sera_pat3` по 230 мс), спрайты в `assets/sprites8.js`, класс `.react-pat` — крупный план по пояс.
- Спрайты крупнее (как DDLC): `.char{height:170%;bottom:-72%}`; NPC: valya 165, liza 182, margo 184, timur 182, father 177 %. POS: left 25 / right 75 %.
- Карта: `map.scenes:{spot:'scene'}` — свой сценарий для точки (без счётчика v_*), `map.follow:'sera'` — пиксельная Сера идёт следом (с репликами), `map.home` — фраза у подъезда; при `scenes` NPC на карте скрыты.
- Кнопки: ветки цветов `.vine.l/.r` вынесены за края (translate ±78%), `.vine.t/.b` — побеги вдоль верхней/нижней кромки; всё `z-index:-1` под текстом. Выборы — шрифт Lora, без разрядки; субтитры — поля 20%.
- Сюжет v5 (после c1_room_*): `c1_room_end` → `c1_gift` (рисунок «Рыжий Первый» + мицеллярка) → 2D-прогулка вдвоём → `c1_shift` (чай в ночную смену) → `c1_room_end2` → `c1_out`. При feel<40: `c1_gift_cold` → одиночная 2D-прогулка → `c1_shift_cold` (шанс извиниться).
- Таракан: `c1_bug` — зум камеры на пол → CG bug1 → катсцена bug2..bug4 (лист наброска, окно, «лети, рыжий»).

## 6. Арт-пайплайн
- Новые спрайты генерировать через Notion MCP `images_generate`, передавая референс Серы neutral на зелёном (session-file ID меняется между сессиями: извлечь `sera_neutral` из `assets/sprites1.js`, наложить на #00FF00 и загрузить через download_file_from_sandbox; старый ID был `session-file://2a12851b-c98c-423f-839e-b4e231811acc`) (Сера neutral, зелёный фон) — «same character, same outfit, same art style, same framing and size, flat pure chroma green #00FF00 background». Для фонов — референс лестницы `session-file://494e8c2e-bd12-4ce4-bca2-30a06fe4f48c`.
- **Проверять анатомию рук**: руки не должны проходить сквозь рукава, Сера не должна держать рукава или лишнюю ткань (в промпте явно: «hands come naturally out of the sleeve cuffs, NOT holding her sleeves, nothing in her hands»). Персонажи должны стоять на полу, а не «левитать» (фон с полом на нижнюю половину кадра).
- Вырезка: `python3 tools/key2.py in.jpg out.webp` (хромакей, высота 1000, despill). Если у персонажа зелёная одежда (Тимур) — генерировать на пурпурном #FF00FF и резать `key2.py in out m`.
- Упаковка: `python3 tools/pack.py assets/spritesN.js sprites key=path.webp …`.
- Сборка единого файла: `python3 tools/build.py` → `/data/serap-s.html` (инлайнит CSS и все `<script src>`).
- Тесты (Playwright, Chromium `/usr/local/bin/chromium`): `cd /data && NODE_PATH=/vercel/sandbox/node_modules node t.js good|bad` — полное прохождение (на карте входит в точки через `__pix.enter`), печатает концовку, состояние и ошибки.
- (tools/ и t*.js лежат в песочнице `/data`, не в репозитории; при потере — пересоздать по описанию.)
