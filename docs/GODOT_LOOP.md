# Godot v18 · «Это не конец»

Дополнение к существующему порту, без замены его сцен, карты, оформления, сейвов и старого сюжета. Веб-оригинал не изменяется.

## Что добавлено
- После любой из семи обычных концовок: её собственное продолжение → первый снег → одна из семи смертей → реакция героя → улика → скример серафима → главное меню.
- Смерти не повторяются, пока герой не увидит все семь. Порядок зависит от концовок, как в веб-версии.
- Память в `user://serap_meta.json`, отдельно от ручных/автоматических сейвов. Загрузка и откат не стирают увиденное. Имя сохраняется между петлями.
- Эхо A/B/C/T, крен реплик, красные строки/вспышки памяти, снег, телефон в 23:47, знамения, монтаж и скример `!ЦЕНОК ЕН ОТЭ`.
- После смерти «Новая игра» недоступна, красное «ПРОДОЛЖИТЬ!» возобновляет текущую петлю или начинает следующий вечер. Загрузка, концовки и настройки сохранены.
- Дизайн кнопок стартового меню — прежний Godot `VineButton`: геометрия, рамки, шрифт, фон, расположение и наведение не менялись. После смерти меняется только текст/цвет надписи «Продолжить» и доступность «Новой игры»; на обычном титуле локальные цветовые переопределения удаляются.
- Восьмая петля: герой отказывается от неправильного выбора, выбирает надёжный ответ; дыхание не проваливается, таймер платформы снят; признание и истинная концовка.
- Заметки «Что я видел», счётчик «Первый снег · N из 7», предупреждение, мягкие вспышки, стирание памяти с подтверждением. Стирание памяти не удаляет ручные сейвы и открытые концовки.

## Архитектура
- `js/story_loop.js` остаётся единственным источником новых сцен.
- `export_data.cjs`: 322 сцены (234 прежних + 88 новых); функции текста вычисляются при экспорте в таблицы вариантов с токенами истории. Никакого eval/JS в Godot.
- `LoopMemory`: память и выбор смерти, динамический текст, выбор правильного ответа.
- `StoryRunner`: дополнительные команды и возврат из сцен-эха; старые переходы не переписаны.
- `LoopOverlay.tscn`: отдельный слой нового контента. Прежние PackedScene остаются на месте.
- Новые изображения извлекаются без перекодирования из имеющихся `assets/loop*.js`. Новые звуки запекаются из исходного WebAudio, как прежние.

## Сборка из репозитория
```bash
node tools/godot/export_data.cjs --assets
node tools/godot/bake_web.cjs
bash tools/godot/fetch_deps.sh
node tools/godot/js_reference.cjs 200
node tools/godot/loop_reference.cjs
cd godot
godot --headless --path . --import --quit
godot --headless --path . --import --quit
godot --editor --path .
```
В готовом ZIP ресурсы уже находятся в `godot/assets/`; достаточно импортировать `godot/project.godot` в **Godot 4.7.2** и нажать **F5** (главная сцена — `scenes/main/main.tscn`).

## Проверки
- 234 прежние сцены структурно совпали с данными `64f440b` без единого изменения.
- 200 старых случайных прогонов совпадают с JS по digest/концовке/статам/заметкам.
- 552 динамические реплики сверены с исходными JS-функциями при разных порядках смертей.
- 49 сочетаний концовок и стадий петли доходят до скримера.
- 200 прохождений восьмой петли не уходят в плохую концовку.
- Реальный UI: предупреждение, красное меню, продолжение, pending после перезапуска, смерть → скример → меню, мягкий режим, отмена отложенных оверлеев, сохранность ручных сейвов, неизменность дизайна кнопок.
- Дополнительно: импорт, компиляция всех GDScript, gdformat/gdlint, GUT и снимки окон через Xvfb/OpenGL llvmpipe.

## Ограничения
Новые эффекты реализованы средствами Godot: вместо CSS-каналов RGB/шума и CSS-инверсии — смена/переворот/тонирование кадров; длительности и сюжетные блокировки сохранены. Гул/ветер запечены в петли, как прежний звук порта. На слух звук не проверен (KI-010); реальный GPU и экспорт этой ревизии не проверены. Старые известные ограничения порта не удалялись.
