# Проверка импорта PC 0.7.5a

## Источник

`SERAPS-PC-0.7.5a-death-details.zip`, проект `SERAPS-Godot-0.7.5a`.
Ветка: `S-erap-S-game`. Основная ветка не изменялась.

## Выполненные проверки

- Исходный проект: Godot 4.7.2 headless, 11 тестовых скриптов, 86/86 GUT-тестов, 2279 assertions — успешно.
- GDScript check-only: CHECK OK. Линтер: без ошибок.
- Проект восстановлен в отдельной папке из базовых файлов и подготовленных GitHub-коммитов, по инструкции README.
- SHA256 архива и каждого из 262 файлов дополнительного пакета проверены.
- После восстановления повторно выполнены 86/86 PC-тестов, 2279 assertions — успешно.

## Совместимость с базовой веткой

В базовой ветке были Android-тесты `godot/tests/integration/test_mobile.gd`, отсутствующие в переданном PC-архиве и несовместимые с его интерфейсами. Пробный запуск с этим старым файлом дал 9 ошибок из 97 тестов. Из новой PC-ветки удалены только этот файл и его UID; тесты PC-проекта и код игры не изменялись ради прохождения тестов. Основная ветка и её Android-тесты сохранены.

## Хранение ресурсов

GitHub MCP принимает текстовые файлы, поэтому бинарные отличия, GUT-ресурсы, исходники арта и точные файлы сценария хранятся в проверяемом tar.gz, разбитом на base64-части в `backup/pc_075a_runtime/`. Восстановление: см. `README_PC_075A_GITHUB.md`.

Кэш `.godot`, генерируемые `.import` и логи не включены. Исторические бинарные бэкапы из архива не продублированы.

## Ограничения

Это техническая проверка, не полное прохождение игры. Графический запуск, Windows EXE и Android APK отдельно не собирались и не проверялись.
