# S^erap^S — визуальная новелла в браузере

Гранж-аниме новелла о Серафиме (Сере) — девушке с розовыми хвостами, острыми ушами в пирсинге и коллекцией крестов, которая сбежала из строгой религиозной семьи.

## Как играть
- Открой `index.html` (или единый `serap-s.html` из релиза) в браузере (работает и с диска, и через GitHub Pages).
- **Клик / Пробел / Enter** — дальше, **Ctrl** — промотка, **A** — авто, **N** — заметки о Сере, **Esc** — меню.
- В пиксельной прогулке: **WASD / стрелки** — идти, **E / Enter** или клик по двери — войти.
- 6 слотов сохранения + автосохранение, журнал реплик, настройки скорости текста и громкости.

## Механики
- **Скрытое доверие** — растёт от терпения и искренности, падает от давления. Шкалы на экране нет: о её отношении можно судить только по поведению.
- **Заметки о Сере** — журнал фактов, которые герой узнаёт о ней сам и от соседей (28 штук).
- **Скрытые флаги**: защитил ли ты её от отца, согласилась ли она пойти к психологу, сколько раз ты давил.
- **3 концовки**: «Свет в конце тоннеля», «Тихая гавань», «Падший ангел».

## Структура
```
index.html        — разметка
css/style.css     — стили
js/story.js       — сценарий и логика концовок
js/engine.js      — движок (текст, выборы, сохранения, эффекты, заметки)
js/pixel.js       — пиксельная прогулка по двору (canvas 320×180)
js/audio.js       — процедурная музыка WebAudio (фортепиано / индастриал / дождь)
assets/*.js       — спрайты и фоны (webp в base64)
docs/concept.md   — концепт-документ
```

## Дизайн персонажа
Стиль и костюм — по референсу concept1 (оверсайз-свитер, чокер, кресты, гольфы, ботинки на платформе), внешность — по YokaFemale (длинные розовые хвосты, банты-крылья, красные глаза, острые уши).

## v2
- Новое главное меню: анимированная Сера на кровати, логотип с розой, чёрно-красная панель кнопок.
- Кнопки подсвечиваются лилово-красным и обвиваются веткой цветов при наведении.
- Сера реагирует на выборы: гладит по голове, показывает язык, подпрыгивает; при наведении на вариант — наклоняется к игроку. Клик по её голове — случайная реакция.
- Главный герой со спрайтами (портрет в диалогах).

## v3
- **Сюжет в трёх главах.** Глава 1 «Соседка» — знакомство, гости в пальто, пастор, ночь на крыше. Глава 2 «Ближе» — три дня прогулок по району. Глава 3 «Решение» — разговор о психологе и концовки.
- **Пиксельный геймплей.** После главы 1 управляешь пиксельным героем: гуляешь по двору и выбираешь, куда пойти (лавочка, кафе «Луна», магазин «24 часа», художественный колледж). В день — два визита, вечером — сцена с Серой, которая зависит от того, что ты узнал.
- **Новые персонажи:** Баба Валя (соседка с лавочки), Тимур (сменщик Серы), Лиза (подруга детства, бариста), Маргарита Павловна (преподаватель живописи).
- **Угрюмая русская крыша**: рубероид в лужах, вентшахты, антенна, трубы ТЭЦ. Сера стоит на крыше, а не висит в воздухе.
- **Анимация бездействия**: дыхание, лёгкое покачивание, смена веса, моргание.
- **8 новых эмоций Серы** (ухмылка, удивление, злость, смех, задумчивость, усталость, обида, нежность), эмоции меняются почти в каждой реплике.
- Диалоги главы 1 переписаны: внутренний монолог героя, свой голос у Серы.
- Убраны шкала доверия и реакция на клик по Сере.
