# S^erap^S — визуальная новелла в браузере

Гранж-аниме новелла о Серафиме (Сере) — девушке с розовыми хвостами, острыми ушами в пирсинге и коллекцией крестов, которая сбежала из строгой религиозной семьи.

## Как играть
- Открой `index.html` в браузере (работает и с диска, и через GitHub Pages).
- **Клик / Пробел / Enter** — дальше, **Ctrl** — промотка, **A** — авто, **Esc** — меню.
- 6 слотов сохранения + автосохранение, журнал реплик, настройки скорости текста и громкости.

## Механики
- **Шкала доверия (система «Трещин»)** — растёт от терпения и искренности, падает от давления.
- **Скрытые флаги**: защитил ли ты её от отца, согласилась ли она пойти к психологу, сколько раз ты давил.
- **3 концовки**: «Свет в конце тоннеля», «Тихая гавань», «Падший ангел».

## Структура
```
index.html        — разметка
css/style.css     — стили
js/story.js       — сценарий и логика концовок
js/engine.js      — движок (текст, выборы, сохранения, эффекты)
js/audio.js       — процедурная музыка WebAudio (фортепиано / индастриал / дождь)
assets/*.js       — спрайты и фоны (webp в base64)
docs/concept.md   — концепт-документ
```

## Дизайн персонажа
Стиль и костюм — по референсу concept1 (оверсайз-свитер, чокер, кресты, гольфы, ботинки на платформе), внешность — по YokaFemale (длинные розовые хвосты, банты-крылья, красные глаза, острые уши).
