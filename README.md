# S^erap^S — Godot

Самостоятельный проект визуальной новеллы **0.7.5a** для **Godot 4.7.2**.

## Запуск

1. Склонируйте репозиторий или скачайте его ZIP.
2. В Godot импортируйте **`godot/project.godot`**.
3. Дождитесь импорта ресурсов и нажмите **F5**.

Все изображения, звуки, музыка, шрифты и GUT уже включены обычными файлами. Для запуска не нужны Node.js, браузерная версия, распаковка base64-архивов или скачивание зависимостей.

- **F9** — админ-панель.
- Сохранения находятся в `user://`, а не в репозитории.
- Это исходный проект, не готовый EXE. Для экспорта нужны шаблоны Godot той же версии.

## Структура

| Папка | Содержимое |
| --- | --- |
| `godot/` | Проект, сцены, код, сценарий, игровые ресурсы, настройки, тесты и GUT |
| `source_assets/` | Исходные библиотеки ассетов, исходники арта, манифесты и контрольные суммы |
| `tools/` | Проверка ресурсов и запуск тестов |
| `.github/workflows/` | Автоматическая проверка Godot-проекта |

`source_assets/embedded/` — сохранённые исходные библиотеки ресурсов старой версии, **не браузерная игра и не зависимость запуска**. Их байты сохранены; движок, HTML/CSS и старые сборочные скрипты удалены из текущей структуры.

## Проверки

Python 3 нужен только для проверки файлов; для самой игры достаточно Godot.

```bash
python3 tools/validate_assets.py
bash tools/test.sh
```

Если Godot не в PATH:

```bash
GODOT_BIN=/path/to/godot bash tools/test.sh
```

`source_assets/SHA256.json` фиксирует контрольные суммы сохранённых ресурсов. При намеренной замене ассета обновляйте и соответствующую сумму, а не отключайте проверку.

## История и права

История коммитов не переписывалась. Старый веб-код, инструкции и резервные копии доступны в предыдущих коммитах и в сохранённой ветке `S-erap-S-game`.

Лицензии GUT и шрифтов сохранены рядом с соответствующими файлами. Исходные манифесты арта находятся в `source_assets/manifests/`. Права и условия использования материалов очисткой не изменяются.
