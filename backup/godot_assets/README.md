# Бэкап бинарных ассетов Godot

GitHub-инструмент агента умеет пушить только текст, поэтому бинарные файлы (фоны `godot/art/**`, звуки, исходники кадров `tools/art/src/m2/*.jpg`) хранятся здесь как `tar.gz`, нарезанный на части по 700 КБ и закодированный в base64.

- `FILES.txt` — список файлов в архиве (108 шт., ~19 МБ).
- `SHA256` — контрольная сумма собранного архива.
- Восстановление: `bash tools/restore_assets.sh` из корня репозитория.

При добавлении новых бинарников бэкап нужно пересобрать (новые части с новым префиксом или полная замена).
