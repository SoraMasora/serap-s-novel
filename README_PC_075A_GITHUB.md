# S^erap^S — PC 0.7.5a

Эта ветка содержит исходники из `SERAPS-PC-0.7.5a-death-details.zip`.
Основная ветка не изменена. Название Git-ветки: `S-erap-S-game` — Git не допускает `^` и пробелы.

## Запуск после клонирования

Нужны Python 3.12+ (или Python 3.11 с поддержкой tarfile data filter), Node.js, Bash и Godot 4.7.2.
Из корня репозитория, строго в указанном порядке:

```bash
bash tools/restore_assets.sh
node tools/godot/export_data.cjs --assets
python3 tools/restore_pc_075a.py
```

Последняя команда восстанавливает точные ресурсы версии 0.7.5a поверх базовых и проверяет SHA256 каждого файла. После неё не запускайте экспорт данных повторно: он перезапишет сценарий и часть ресурсов.
Откройте `godot/project.godot`, дождитесь импорта и нажмите F5. Админ-панель — F9. Это исходный проект, не готовый EXE.

## Что включено

- Сценарий, сцены, скрипты, админ-панель и тесты из переданного проекта.
- Графика, шрифты и звук Godot: бинарные отличия сохранены без потерь в `backup/pc_075a_runtime/part*.b64`, по принятой в репозитории схеме.
- Описание ретуши: `README_075A_DEATH_DETAILS.txt`; полный перечень ресурсов — `backup/pc_075a_runtime/FILES.txt`.
- Временные логи, Godot-кэш и автоматически генерируемые `.import` не включены. Исторические бинарные резервные копии из архива не дублируются; исходный бэкап репозитория сохранён.
